# Stardust Engine Book Library

This repository contains the standalone, straight-CSS implementation of the **Stardust Engine Book Library**. It serves as the dedicated reading interface for Raggiesoft Narratives, hosted at `books.raggiesoft.com`.

By keeping this repository entirely decoupled from the legacy Raggiesoft.com UI (no Web Awesome, no Font Awesome), the book reader is highly optimized, unopinionated, and strictly focuses on providing a clean, distraction-free reading environment.

## Routing
Per the Raggiesoft Security through Obscurity protocol, public requests are routed through a hidden PHP structure (the "Chloe/Isabel" matrix) mapped via Nginx.
